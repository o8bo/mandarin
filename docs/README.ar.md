# Mandarin for Linux Mint

تطبيق سطح مكتب مستقل لتحويل الملفات محليًا، مستوحى من طريقة استخدام Tangerine.
هذه نسخة أولية قابلة للاستخدام؛ لا تدّعي مطابقة كل صيغ وأدوات تطبيق ماك.

## التشغيل

شغّل `./launch.sh`، أو افتح **Mandarin** من قائمة تطبيقات لينكس بعد التثبيت.

1. أضف ملفات أو مجلدات، أو اسحبها إلى مساحة الإفلات.
2. اختر **Convert** للتحويل، أو **Tools** للأدوات، أو **Actions** لإجراءات الملفات.
3. اختر العملية واضبط إعداداتها. النتائج تُحفظ بجانب المصدر، أو في المجلد الذي تختاره.

العمليات التي تتطلب معاملات مثل القص أو تغيير الحجم تفتح نافذة إعدادات أولًا.
إغلاق النافذة يبقي التطبيق في شريط النظام إن كان متاحًا. استخدم **Quit Mandarin** للخروج.

## العجلة أثناء السحب — X11

ابدأ سحب ملف أو مجموعة ملفات من Nemo، ثم اضغط المفتاح بعد بدء السحب:

| المفتاح | القائمة |
|---|---|
| Shift | صيغ التحويل |
| Alt | أدوات التعديل |
| Ctrl | إجراءات الملفات |

اترك المفتاح، وحرّك الملف إلى القطاع المطلوب ثم أفلته. القطاع الأوسط يفتح النافذة.
**More** يعرض باقي العمليات. Escape يلغي العجلة. يمكن تعطيلها من Settings.
العجلة العامة تتطلب X11؛ مساحة الإفلات داخل النافذة تعمل أيضًا على Wayland.

## الوظائف المتاحة

| المجموعة | التحويلات والأدوات |
|---|---|
| الصور | PNG / JPEG / WebP / TIFF / BMP / ICO / GIF / PDF؛ تغيير الحجم، الدوران، القص، الرمادي، الضغط، إزالة البيانات الوصفية |
| الصوت | MP3 / WAV / FLAC / OGG / M4A / Opus / AIFF؛ القص وتسوية شدة الصوت |
| الفيديو | MP4 / MOV / MKV / WebM / GIF، استخراج الصوت؛ القص والضغط وإزالة الصوت |
| PDF | PNG / JPEG / نص؛ الدمج، التقسيم، الدوران، استخراج الصور المضمّنة |
| المستندات | DOC / DOCX / ODT / RTF / TXT إلى الصيغ الملائمة عبر LibreOffice، ومنها PDF |
| الجداول | XLS / XLSX / ODS / CSV / TSV إلى XLSX / ODS / CSV / TSV / PDF |
| العروض | PPT / PPTX / ODP إلى PPTX / ODP / PDF |
| الترجمة | SRT / VTT / TXT، مع الحفاظ على توقيت المقاطع عند التحويل بين SRT وVTT |
| الأرشيفات | إنشاء ZIP / TAR / TAR.GZ، واستخراج ZIP وأنواع TAR المدعومة |
| إجراءات الملفات | نسخ الملفات أو المسارات، النسخ أو النقل إلى مجلد، فتح الموقع أو الطرفية، معاينة الصور والنصوص |

الخيارات تُصفّى حسب نوع الملفات والمحركات المتاحة. التحويل قد يفشل إذا لم يدعم المحرك ترميز الملف أو كان تالفًا؛ تُعرض رسالة الخطأ والنتائج المكتملة.

## حدود واضحة

- لا توجد AirDrop أو صيغ Apple Pages أو محاكاة لتطبيق ماك نفسه.
- HEIC وSVG وEPUB وMarkdown ليست مدعومة كصيغ تحويل متخصصة في هذا الإصدار.
- لا تحويل دقيق من PDF إلى Word/Excel/PowerPoint، ولا OCR.
- الصور المتحركة تعالج كإطار أول؛ يُعرض ذلك في الواجهة.
- قد يغيّر LibreOffice تفاصيل تخطيط المستندات المعقدة. تحويل الجداول إلى CSV/TSV يعالج ورقة العمل التي يصدرها LibreOffice افتراضيًا، وليس مصنفًا متعدد الأوراق كاملًا.
- الإعدادات وسجل العمليات مؤقتة خلال جلسة التطبيق.
- لا يوجد تشغيل تلقائي مع تسجيل الدخول. افتح التطبيق لتفعيل العجلة.

## حماية الملفات والخصوصية

المعالجة محلية. لا حسابات أو خادم تحويل أو تحليلات استخدام.
التحويلات تكتب نسخًا جديدة ولا تستبدل الملفات الموجودة؛ عند تصادم الاسم يُضاف رقم.
يتم تجهيز النتيجة في مجلد مؤقت ثم نشرها بعد اكتمالها. إلغاء دفعة يحافظ على النتائج المكتملة ويعرضها في السجل.
النقل إجراء صريح يتطلب اختيار الوجهة وتأكيدًا، بخلاف التحويلات التي تحفظ المصدر.
استخراج الأرشيفات يرفض تجاوز المسار والروابط والملفات الخاصة، ويضع حدًا قدره 10,000 عنصر و2 GiB.

## التثبيت وإعادة التثبيت

```bash
python3 install.py
```

ينشئ نسخة خاصة بالمستخدم في `~/.local/share/mandarin` ومشغّلًا في قائمة التطبيقات.
يرفض استبدال تثبيت سابق تلقائيًا. لإزالة التطبيق: اخرج منه، ثم احذف مجلد التثبيت
والملف `~/.local/share/applications/mandarin.desktop`. لا تُحذف ملفاتك المحوّلة.

المتطلبات النظامية على Linux Mint 22: Python 3، GTK 3، PyGObject/Cairo وPillow،
وLibreOffice وPoppler للوظائف ذات الصلة. FFmpeg/FFprobe وpypdf مجهزان محليًا في `vendor/`.
حزمة FFmpeg مستخرجة من مستودع Ubuntu Noble وتعتمد على مكتبات FFmpeg الموجودة في النظام؛
لذلك الحزمة المحمولة مخصصة لهذا الجيل من Linux Mint x86-64.

## واجهة الطرفية

```bash
./launch.sh --capabilities
./launch.sh --list /path/to/photo.png
./launch.sh --operation image:jpeg /path/to/photo.png
./launch.sh --operation image:resize --options '{"width":1280,"height":720}' /path/to/photo.png
./launch.sh --operation pdf:merge first.pdf second.pdf
```
